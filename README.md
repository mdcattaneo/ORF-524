# ORF 524: Statistical Theory and Methods

This repository contains the student facing materials for ORF 524 at Princeton University. The course is instructor led and AI integrated: the Markdown chapters provide the stable mathematical spine, while AI is used for explanation, critique, examples, and guided practice. Independent mastery is assessed through closed book examinations.

- [Current syllabus](ORF524-Fall2026-Syllabus.pdf)
- [Course AI guide](AGENTS.md)
- [Practice assignment guide](assignments/README.md)
- [Past exams and solutions](exams/README.md)
